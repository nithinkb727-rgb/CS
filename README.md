# CS Quiz App

A lightweight, browser-based computer science quiz app built with vanilla HTML, CSS, and JavaScript.

## Features

- 8 multiple-choice CS questions.
- Instant answer feedback (correct/wrong styling).
- Running score display.
- End-of-quiz summary with restart button.

## Run locally

You can open `index.html` directly in a browser, or serve the folder with a static file server:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
